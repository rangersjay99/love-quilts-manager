COMBINED ENTRY SAFETY
- Create Need & Distribute changes local data in one save operation.
- The incoming transaction, optional linked OUT distribution, and charity need share the same sourceNeedId.
- Firebase Sync sends changed transaction and need documents through one Firestore write batch when the queued save is flushed.
- If Distribute Now is 0, only the incoming transaction and need are created.
- If internet service is unavailable, the complete entry remains saved locally and the existing pending-save queue retries it.
