# Love Quilts Manager

Current release: Update 7.8.47 — July 31, 2026

## Update 7.8.47 — Printing, Audit, Worksheet, and Logo

- Opens the iPhone/iPad print request directly from the original tap instead of waiting for fonts and a delayed timer.
- Counts active Unassigned/Storage records in appropriate totals while preserving exact charity-and-size shortage matching.
- Deleted active records are removed from all Home, Calendar, inventory, report, yearly, and planning totals.
- A synchronized Audit History retains creates, edits, deletions, list changes, restores, and resets without affecting operational totals.
- Adds a printable blank inventory-and-needs worksheet based on the current charity and quilt-size lists.
- Adds a synchronized custom logo for the splash screen, app header, and printable HTML reports, with safe resizing and original-logo reset.
- Existing Firebase organization, transaction, and need paths remain unchanged.
