# Love Quilts Manager

Current release: Update 7.8.46 — July 29, 2026

## Update 7.8.46 — Exact Charity-and-Size Planning Totals

- Uses only inventory matching the exact charity and quilt size when calculating quilts still to be made.
- Does not assume that quilts in a different size will be swapped to meet a request.
- Shows current usable inventory, exact-match inventory, and other inventory not matched to a current need separately.
- Formula with the July 29 backup: 347 remaining calendar need − 155 exact-match inventory = 192 still to make.
- Projected Total Quilts Made by Year End: 282 made so far + 192 still to make = 474.
- Excludes Unassigned/Storage test activity from official made, distributed, storage, yearly, and lifetime totals.
- Retains the printing protections and Custom Reports added in Update 7.8.43.
- Existing Firebase production paths, saved records, exports, and backup formats remain unchanged.
