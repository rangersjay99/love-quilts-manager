# Love Quilts Manager

Current release: **Update 7.8.35 — Settings Cleanup and Single Calendar — July 26, 2026**

## Update 7.8.35

- Makes “Designed to grow with your quilting needs.” on the splash screen open Settings directly to Future Modules.
- Groups the long Settings page into six short tap-to-open sections. Only one section remains open at a time.
- Shows only the newest two Change Log entries until Show All Updates is selected.
- Removes the duplicate 12-month Calendar from the Quilts Needed tab.
- Keeps the Home screen Calendar as the single Calendar view, including its edit, distribute, details, and print actions.
- Makes no Firebase schema, stored-data, inventory-calculation, or report-calculation changes.

## Installation

Upload all included files to the existing GitHub repository, replacing the older files. Keep the `icons` folder. After deployment, open the app and confirm Update 7.8.35 appears on the splash screen or About section.
