# Love Quilts Manager

Current release: **Update 7.8.22 — Calendar Simplification and Portrait Print — July 24, 2026**

## Update 7.8.22

- Calendar month cards no longer repeat an **Add Quilts Needed** button.
- Add requests through the existing **At a Glance → + Add Need** action.
- The Home Calendar no longer repeats an instruction above the calendar.
- Each populated month card ends with a subtle **Tap charity to edit** note.
- **On Hold / Storage** is removed from the active Home and Inventory workflow and returned to the future roadmap.
- Existing deferred record data is preserved internally during upgrades; it is not exposed as an active feature.
- The printable 12-month Calendar is now **US Letter portrait**, arranged as 3 columns × 4 rows.
- Calendar entry actions, bottom key, status colors, yearly statistics, Sync Now, Set Current Count, report improvements, and distribution safeguards remain.
