# Love Quilts Manager

Current release: Update 7.8.45 — July 29, 2026

## Update 7.8.45 — Pooled Inventory Planning Totals

- Uses current usable inventory pooled across sizes within each charity when calculating quilts still to be made, because quilts may be swapped between sizes within the same charity.
- Formula: Still to Be Made = Remaining Calendar Need − Current Usable Inventory.
- Projected Total Quilts Made by Year End remains Made So Far + Still to Be Made.
- Keeps exact charity and size details on individual calendar entries.
- Excludes Unassigned/Storage test activity from official made, distributed, storage, yearly, and lifetime totals.
- Retains the printing protections and Custom Reports added in Update 7.8.43.
- Existing Firebase production paths, saved records, exports, and backup formats remain unchanged.
