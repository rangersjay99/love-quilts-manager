# Love Quilts Manager

Current release: Update 7.8.62 — August 8, 2026

## Update 7.8.62 — Today’s Activity / Daily Changes

- Adds a read-only Today’s Activity / Daily Changes section under Reports.
- Defaults to today and allows review of another selected date.
- Shows saved changes in chronological order with time, signed-in user, action, charity, size, quantities, activity/distribution date, and concise before/after details where applicable.
- Shows net daily effects for inventory, quilts made/received, and distributed quilts so corrections and deletions are not double-counted.
- Separately counts need records changed and summarizes bulk intake, needs, distribution changes, adjustments, and settings/list changes.
- Adds a Daily Changes CSV download for the selected date.
- Uses the existing synchronized Audit History as its source and is completely read-only.
- Existing inventory, needs, report calculations, Firebase production paths, sync rules, and saved operational records are unchanged.

Update 7.8.61 unsaved-entry protection and one-size auto-fill remain in place.
