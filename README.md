# Love Quilts Manager

Current release: **Update 7.8.40 — Custom Growth Message and Bottom Tabs — July 26, 2026**

## Update 7.8.40

- Adds the Future Modules message to the Home screen as well as the splash screen.
- Makes the Future Modules message customizable under **Settings → Names, Wording & Tabs**.
- Keeps the message clickable so it opens Settings directly to Future Modules.
- Makes all five bottom navigation labels customizable: Home, Inventory, Quilts Needed, Reports, and Settings.
- Keeps tab icons, colors, order, and destinations fixed to prevent navigation mistakes.
- Moves Names and Wording above Manage Lists so the customization fields are easier to find.
- Synchronizes the new wording between approved devices and includes it in backups.
- Does not change inventory, request, distribution, report, or yearly-statistics calculations.

## Install

Upload all included files to the existing GitHub repository, replacing the older files. Keep the `icons` folder. After deployment, open the app and confirm Update 7.8.40 appears on the splash screen or About section.
