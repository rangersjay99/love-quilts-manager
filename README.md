# Love Quilts Manager

Current release: Update 7.8.57 — August 5, 2026

## Update 7.8.57 — Editable Header Tagline

- Adds a Header Tagline setting under Settings → Names, Wording & Tabs.
- Changes the line directly beneath the app title on every main page.
- Leaving the field blank restores the standard wording: “Available quilts, requests, and quilts still to complete.”
- The saved tagline synchronizes to approved devices through the existing Firebase settings document.
- Inventory, charity needs, reports, calculations, Firebase paths, and saved-data structure remain unchanged except for this optional wording field.
- Includes all improvements through Update 7.8.56.
