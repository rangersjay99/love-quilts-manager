UPLOAD
1. Extract Love_Quilts_Manager_Update_7_8_47.zip.
2. Upload every extracted file to the repository main/root folder.
3. Replace files with the same names.
4. Keep the icons and firebase-test folders.
5. Wait for GitHub Pages to publish.
6. Close and reopen the installed app on each device. Refresh once if an older version remains cached.
