Love Quilts Manager Update 7.8.67

Upload the extracted update files to the root of the existing rangersjay99/love-quilts-manager GitHub repository on the main branch, replacing files with the same names. Do not upload the enclosing folder. Leave the firebase-test folder unchanged.

This update corrects Custom Reports current-inventory grouping. When Charity is not selected and Quilt size is selected, each size is listed once with quantities combined across charities. When Charity is selected, separate charity totals remain. No data migration is required.

After GitHub Pages publishes, fully close and reopen the app while online so the updated service-worker cache loads. Confirm the splash screen shows Update 7.8.67.
