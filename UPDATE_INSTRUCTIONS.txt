LOVE QUILTS MANAGER — UPDATE 7.8.61
Released: August 8, 2026

BEFORE UPDATING
1. In the app, export a current Backup from Settings.
2. Confirm approved devices show All changes synced.
3. Download a ZIP backup of the current GitHub repository.

UPLOAD
1. Extract Love_Quilts_Manager_Update_7_8_61.zip.
2. In the GitHub repository main/root folder, upload every extracted file and replace files with the same names.
3. Do not delete or replace the firebase-test folder if it exists in the repository.
4. Wait for GitHub Pages to publish.
5. Close and reopen the installed app on each device. Refresh once if an older version remains cached.

IMPORTANT
- This full package is based on Update 7.8.60.
- It does not clear, migrate, or reinitialize shared inventory.
- Do not choose Create Real Shared Inventory again.
- Firebase production collection paths and transaction/need saved-data schemas are unchanged.
- Update 7.8.61 adds no new synchronized data fields.
