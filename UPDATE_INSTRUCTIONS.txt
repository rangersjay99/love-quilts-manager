LOVE QUILTS MANAGER — UPDATE 7.8.62
Released: August 8, 2026

BEFORE UPDATING
1. In Love Quilts Manager, confirm Shared Device Sync says all changes are synced.
2. Export a current app Backup from Settings.
3. Download a ZIP backup of the current GitHub repository.

UPLOAD
1. Extract Love_Quilts_Manager_Update_7_8_62.zip.
2. Upload all extracted files to the main/root folder of the Love Quilts Manager GitHub repository and replace files with the same names.
3. Do not delete or replace a separate firebase-test folder if it exists in the repository.
4. Wait for GitHub Pages to publish.
5. Close and reopen the app. Refresh once if Update 7.8.61 remains cached.

IMPORTANT
- Update 7.8.62 adds no new operational data fields or Firebase paths.
- Today’s Activity is read-only and uses the existing synchronized Audit History.
- Audit History retains the latest 200 entries; the app clearly notes when that retention limit could make an older selected date incomplete.
- Existing inventory, needs, calculations, combined entry, bulk intake, eligible sizes, and unsaved-entry protection remain unchanged.
